Workflow Description

Step 1: User Login
The user opens the web application and enters their login credentials. The authentication module verifies the credentials.

Step 2: User Authentication and Access
After successful authentication, the user's assigned role is identified. Access to application functionality is controlled according to role permissions.

Step 3: Dashboard
The user is directed to the dashboard, which provides access to shipment information, compliance details and other application functions.

Step 4: Shipment Monitoring
The application retrieves shipment-related information from the shipment database and displays the available shipment and compliance details.

Step 5: Deviation Management
Users with the required permissions can access deviation records, create or update deviations, manage their status and maintain the associated event history.
The deviation workflow includes:
Open
Under Investigation
Corrective action
Closed

Step 6: PDF Report Generation
The application prepares the required report information and generates a downloadable PDF report.

Step 7: User Management
Authorized administrative users can manage application user accounts according to their assigned permissions.

Step 8: Return to Dashboard
After completing an operation, the user can return to the dashboard and select another available operation.

Workflow Outcome
The workflow provides a structured process for user authentication, shipment monitoring, deviation tracking, user management and report generation within the Cold Chain Management System.
